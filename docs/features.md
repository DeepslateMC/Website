# Features
This is a list of the current features:

- Discord link commands
- Ability to clear the chat
- Setting a buildworld for builders
- Maintenance mode
- Option to disable the op command
- Configurable /help output
- Spawn commands
- Ability to disable knowledgebook clicks
- Toggleable move error messages
- Configurable debug menu brand
- Simple Tablist decoration
- Custom playerlist hover text
- Custom bossbar to display your text
- Custom actionbar message
- MiniMessage support for the MOTD
- Option to not show spectator mode players modified in the tablist
- Option to add server links to the game pause menu
- /unbreakable command to make an item unbreakable
- Option to hide all players from the tablist (including yourself)
