# Commands
## Deepslate
`/deepslate reload` - Reloads the deepslate.yml and messages.yml files

`/deepslate version` - Shows information about DeepslateMC

## Discord
`/discord` - Shows the configured Discord link

`/dc` - Does the same thing

## ClearChat
`/clearchat` - Clears the chat

`/cc` - Does the same thing

## Buildworld
`/buildworld` - Teleports the player to the spawn of the set world

`/setbuildworld` - Sets a world

## Maintenance
`/maintenance` - Toggles the maintenance mode

## Help
`/help` - Shows the configured help message

## Spawn
`/spawn` - Teleports the player to the spawn

`/lobby` - Alias for /spawn

`/setspawn` - Sets the spawn

## Unbreakable
`/unbreakable` - Makes the item in your hand unbreakable
