# Files
On the following pages, you will be able to find information about the configuration files added by `DeepslateMC`.

## Config file
The config file is found in the `/deepslate` directory inside your server. It is called `deepslate.yml`. Here you can configure the functionality of the various [features](/docs/features) added by this software.

You can find an explanation of all the options here: [Config](/docs/files/config)

## Messages file
The messages file is also found in the `/deepslate` directory inside your server. It is called `messages.yml`.

You can find more information here: [Messages](/docs/files/messages)
