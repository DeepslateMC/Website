# Messages File
The `messages.yml` file is located in the `/deepslate` directory next to the `deepslate.yml` file.

In it, you can adjust almost all messages being sent to players from this software to your needs.

## MiniMessage
The `messages.yml` file uses the [MiniMessage](https://docs.papermc.io/adventure/minimessage/format/) format. With it, you can easily craft beautiful messages with advanced features like gradients or on-click actions.

If you are new to MiniMessage or prefer a live preview, you can use the [MiniMessage Web Editor](https://webui.advntr.dev/).
